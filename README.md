# deploy-eu.github.io

Source of the Deploy@EU community website: https://deploy-eu.github.io

A single static page (`index.html`) with self-hosted fonts (`fonts/`, SIL Open Font License). No cookies, no tracking, no build step.

- Cases live in [deploy-eu/case-library](https://github.com/deploy-eu/case-library).
- Text is available in English, Chinese, German, French, Italian and Spanish; translations are in the `d(...)` lines near the top of the script.
